# E-commerce Spring Boot Application

This is an e-commerce web application built using Spring Boot.

## Tech Stack
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- MySQL
- Maven

## Features (In Progress)
- User Registration & Login
- Product Listing
- Cart Management
- Order Placement
- Admin Product Management

## Status
🚧 Project under active development.
